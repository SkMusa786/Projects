# 🚀 JavaScript Mini Projects

A collection of beginner-friendly JavaScript projects built using **HTML**, **CSS**, and **JavaScript**. These projects helped me strengthen my understanding of DOM manipulation, event handling, asynchronous JavaScript, and working with APIs.

## 📌 Projects Included

### 1. ✊✋✌ Rock Paper Scissors

A fun browser-based Rock Paper Scissors game where the user plays against the computer.

### 🔗 Live Demo
👉 https://skmusa786.github.io/Projects/Rock_pap_scisor/

### ✨ Features
- Interactive UI
- Random computer move generation
- Instant result display
- Score tracking
- Responsive design

### 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## 💱 Currency Converter

A real-time currency converter that converts one currency into another using a live exchange rate API.

### 🔗 Live Demo
👉 https://skmusa786.github.io/Projects/Currency_converter/Currency_converter/

### ✨ Features
- Convert between multiple currencies
- Live exchange rates
- Country flags for selected currencies
- Swap currencies
- Responsive interface
- Error handling for invalid inputs

### 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Exchange Rate API

> **Note:** This project uses an **API Key** to fetch real-time exchange rates.

```bash

```

2. Navigate to the project folder

```bash

```

3. Open the desired project's `index.html` file in your browser.
